## 测试覆盖的关键约束

1. 每批关系调用都收到完整原文；跨章节关系保留；孤立概念保留。
2. 伪造知识点、伪造端点、无效引用、仅覆盖一端的关系证据被拒收。
3. 同名不同定义保留，重复定义保守合并。
4. 大章节完整覆盖，Unicode 引用位置正确，Windows CRLF 转换后证据位置稳定。
5. 完整文档 / 提示词超预算失败，不进行隐式截断。
6. 模型不完整输出、拒答和非法 JSON 失败；Docling 部分成功也不作为完整文档通过。
7. 阶段顺序约束、已完成阶段幂等、重复任务启动拒绝。
8. 文档类型 / 大小 / 空文件、API 密钥、跨源请求与不存在任务处理。
9. 图谱与四种导出；否决关系后图形导出移除边，同时保留节点和 JSON 审计记录。
10. 模型配置持久化、读取不回传密钥、换接口主机不能隐式复用旧密钥、运行任务期间不允许切换模型。
11. 服务错误持久化且不回传厂商的原始敏感错误正文。
12. Compose YAML、n8n JSON 的服务名、节点阶段和内部地址契约。
13. n8n 连接拒绝、404 未发布、401 认证失败、500 错误分别显示明确原因；状态同时持久化。响应超时保持查询，防止重复提交；无效 200 响应不能冒充有效任务确认。
14. 思考强度与输出预算在 Responses / Chat Completions 两种协议中使用对应字段发送。
15. 输出上限触发关系源节点批次二分，全部概念与全文保持不变；失败重试保留已完成阶段及失败历史，运行中任务拒绝重复重试。
16. 全文重要性筛选只能选择已有 ID；未知/重复 ID、不同名称的合并及超预算结果拒收。同名异义可分别保留，同名同义合并全部证据；未选择概念不进入关系请求，空选择产生有效空图。
17. 关系预算和具体联系优先规则、重复泛泛关联剔除、全文关系复核不可创造关系，所有筛除都有审计记录。
18. PDF 空格/换行差异可恢复到精确原文切片；非空白改写和跨块引用仍被拒收。
19. 0 / 1 / 18 / 61 节点图的确定性布局，节点不重叠、路径不穿节点、方向和全部关系保留、主干无环。SVG / draw.io 共用布局并支持主干和全部关系范围。
