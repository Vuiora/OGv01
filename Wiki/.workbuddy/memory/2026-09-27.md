### 关键技术结论（重要，可复用）
- **Docker 镜像源**：本机 `registry-1.docker.io` 不通，用
  `~/.docker/daemon.json` 配 `https://docker.m.daocloud.io` 镜像加速。Docker Desktop
  可执行文件在 `C:\Users\Lenovo\AppData\Local\Programs\DockerDesktop\Docker Desktop.exe`。
- **Bot 密码字符集陷阱（踩坑最久）**：MediaWiki 的
  `BotPassword::canonicalizeLoginData()` 只在密码匹配 `^[0-9a-w]{32,}$` 时才走 bot
  登录分支，否则退化为普通账号认证并返回笼统的 `wrongpassword`。用大写字母、`x/y/z`
  或 `-` 都会导致登录失败，**而密码哈希本身 verify 是 true**，极易误判为账号问题。
  → 生成密码务必限定字符集 `0123456789abcdefghijklmnopqrstuvw` 且长度 ≥32。
- **Bot 密码登录走 `action=login`**（`ApiLogin.php` 中 BotPassword::login 分支），
  不是 `clientlogin`（后者不走 bot 分支）。curl 传 token 时 shell 转义会破坏 `+\` 结尾的
  token，用 Python requests 更可靠。
- **用户名词首字母大写**：`createBotPassword admin ...` 会失败，必须用 `Admin`。
- **`--grants` 取值**：是 `editpage`/`createeditmovepage`/`uploadfile`/`highvolume`/
  `basic` 等，不是 `edit`/`createedit`/`upload`（用 `--showgrants` 查全部）。
- **`website` 容器 sysop 组**：bot 组权限需在 LocalSettings 显式给。
- **模板表格空段落**：wikitext `{|` 表格里，`{{#if:...}}` 为空时残留的换行会生成
  `<p><br/></p>`。改用 **HTML `<table>` 写模板**可彻底避免。
- **CSS 浮动信息框**：模板用 `float:right` 时，正文会正确环绕；用
  `document.createRange().getClientRects()` 逐行比较可精确判定是否真侵入。
- **环境**：`rapidocr 3.9.2` + onnxruntime 已装在
  `C:/Users/Lenovo/.workbuddy/binaries/python/envs/default/`，71 页 OCR 约 3.5 分钟。
  运行前需 `PYTHONPATH=` 清空以避免 safe-delete 钩子干扰。

  (`C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe`) + playwright-core
  （在 node workspace）headless 截图。

## 任务：导入《动手学深度学习》（D2L）到 Wiki

### 背景
用户上传 `C:\Users\Lenovo\Downloads\d2l-zh-pytorch.pdf`（797 页），要求导入 wiki。
经确认：**全书导入 + 一节一页 + 仅 PyTorch 代码**。

### 关键决策：用官方 Markdown 源码，不用 PDF 抽取
PDF 由 LaTeX（xdvipdfmx）排版，公式被拆成 Type1 字体碎片（CMR10/CMMI10/CMSY7），
无法还原 LaTeX。而 `raw.githubusercontent.com` 可达，故直接拉 `d2l-ai/d2l-zh`
（master）的 141 个 `.md` 源文件——公式是完整 LaTeX、代码保留缩进，质量远高。

### 产出
1. **141 个 wiki 页面**（20 章 + 121 内容节 + 总索引），零红链；
   4254 个 MathML 公式、979 个 PyTorch 代码块、184 张插图、20 个分类。
2. 套件落 `wiki-deploy/d2l/`：`md2wiki.py`（转换器）、`import_d2l.py`（导入）、
   `verify_all.py`、`pages/*.wiki`（唯一事实来源）、`README.md`（含全部踩坑）。
   过程产物在 `.build/d2l/`（src/、img/、各分析脚本）。
3. 首页新增 D2L 索引表，两套知识体系（计算机数学基础 / 动手学深度学习）互通。
4. `wiki-deploy/` 新增 `uploads.ini`（PHP 上传限制提至 32M）+ compose 挂载 +
   `$wgMaxUploadSize`，解决 `twogpu.svg`(2.8MB) 超限。

### 转换器关键坑（可复用，详见 d2l/README.md）
- **tab 分组**：连续代码块成组，取含 `pytorch` 的块（否则 `all`）；
  **整组无 pytorch/all 时必须消费围栏**，否则残留围栏被行内正则误渲染
  （曾致 `(**kwargs)` 跨段落误匹配、TF/mxnet 代码泄漏）。
- **`(**..**)`/`[**..**]` 可跨行**，且须先屏蔽 `<syntaxhighlight>` 再处理行内。
- **`:eqlabel:` 也是 label**，漏掉会导致 `:eqref:` 全部失效。
- **页面重名**：章索引与首节同名（多层感知机、循环神经网络），用 TITLE_OVERRIDE 消歧。
- **公式渲染**：native 模式已验证支持 aligned/bmatrix/cases + \mathbf/\mathbb/
  \mathcal/\boldsymbol/\underbrace，无需外部服务。
- **图片文件名**：下载时加 `img__` 前缀（源自路径 `img/xxx`），导入时需回补前缀查找。
