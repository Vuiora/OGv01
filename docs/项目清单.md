## 原有问题与运行限制

- Mentor 设计文档中的“仅有方案”已落后于当前工作目录，但源码仍缺完整入口和测试；用本清单描述实际状态。
- SDL 根 README 与安装配置仍主要面向 M1，后续模块从目录源码运行；具体契约见 `INTERFACES.md`。
- PRT 示例只是早期系统练习，尚未形成推理组件或完整的统一构建入口；迁移不替代其功能开发。
- 部分启动、转换与示例脚本包含原机器绝对路径；目录布局已保留，相对路径引用继续对应同级项目，绝对路径需要本地调整。
- 运行数据库、已安装依赖与模型权重未上传；源码克隆完成后依据各 README 安装与初始化。
- SDL 有两项原有授权／审计契约测试失败；PLDA 在 Python 3.12 下有一项时间戳断言失败，详见 [整合验证记录](VERIFICATION.md)。

精确的文件散列、脱敏文件和排除路径见 `migration-manifest.json`。不存在 Git 的项目只有此次导入提交，无法恢复它们从未记录过的旧历史。
