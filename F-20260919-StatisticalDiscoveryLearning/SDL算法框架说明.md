# SDL 算法框架说明

版本：v0.1｜性质：研究设计与可实现原型

## 1. 定位与设计原则

SDL（Statistical Discovery Learning，统计发现学习）旨在从观测数据中构造概念、提出可检验假说，并通过独立证据逐步筛选、修订和积累发现。此前讨论曾使用 StatDL 缩写，本文按当前需求统一使用 SDL。本框架是待验证的设计方案，不代表已经建立的新理论或成熟算法。

SDL 的产物是带适用范围、来源、反例和不确定性的发现档案。发现类型可以包括关联、分类、方程、不变量、变点和机制候选。机制候选需要额外的因果识别条件或干预证据；统计关联本身不构成因果证明。

算法由“探索—冻结—确证—更新”组成。探索阶段允许高频搜索与修订；确证阶段执行预定协议。简洁、新颖的解释可以优先接受检验，但不能绕过证据门槛。

## 2. 八个模块及输入输出

| 模块 | 主要输入 | 主要输出 |
|---|---|---|
| M1 问题定义与数据治理 | 研究问题、原始数据、知识库、预算 | 观测单位、目标、发现类型、质量记录及三类数据分区 |
| M2 表示与概念构造 | 探索数据、领域约束、知识库版本 | 特征、关系、候选概念及可执行变换 |
| M3 模式搜索 | 探索表示、搜索算子 | 关联、分群、方程、不变量、变点等模式 |
| M4 多假说构造 | 模式、候选概念、背景知识 | 结构化假说池、零假说及竞争解释 |
| M5 开发评估与筛选 | 假说池、探索数据、开发评估数据 | 稳定性与预测收益、复杂度、新颖性、候选排序 |
| M6 冻结与独立确证 | 冻结候选、检验协议、未见确证数据 | 支持、反驳或证据不足，以及效应量和不确定性 |
| M7 主动取证与反例搜索 | 竞争假说、边界条件、未决问题 | 区分性观测、实验或复现计划及所需数据 |
| M8 假说更新与知识归档 | 确证结果、反例、来源与版本记录 | 新版知识库、假说修订或退役、发现档案 |

M2—M5 构成探索区；M6 构成确证区。M7 服务于下一轮取证，M8 保存完整历史并将可用信息送回探索。数据访问策略、资源预算和审计日志贯穿所有模块。

M1 的形式化定义、观测与质量模型、数据分区、访问状态、条件性统计命题及实现契约，详见 [模块 01：数据与证据协议的理论描述](SDL模块01-数据与证据协议.md)。

实现时，将搜索过程设为受预算约束的插件管线：

| 子过程 | 初版算法与操作 | 保留的输出 |
|---|---|---|
| 概念构造 | 在受限表达式语法中枚举加、减、乘、除及有定义域的变换；限制深度、节点数与量纲 | 可计算的新变量及定义域 |
| 关系与方程 | 对候选变量做回归、稀疏项选择、表达式搜索，并与常数及简单线性基线比较 | 关系式、误差、残差与复杂度 |
| 结构模式 | 按任务调用聚类、变点、周期或不变量检测；检查重采样下的结构稳定性 | 子群、阈值、周期或近似守恒量 |
| 假说生成 | 将模式转成结构化对象；LLM 提出解释与替代假说，随后由执行器补齐数值证据 | 可证伪陈述、预测、范围和竞争解释 |
| 去重与剪枝 | 合并规范化后的等价表达式；剔除不合法定义域、单位冲突及被其他候选支配的方案 | 大小受限的候选池 |

可从表达式深度不超过 3、每轮保留 50 个探索候选、最多冻结 5 个确证候选开始。这些数字是原型配置，应在探索资料上调试。保留不同结构的候选，避免候选池只剩同一公式的微小参数变体。LLM 生成的代码须经检查并在隔离执行环境运行。

主动取证优先选择假说预测分歧大、接近适用边界、且采样成本可承担的观测。原型可用“候选预测分歧 / 采样成本”排序；它是启发式，只有另行定义假说概率、观测模型与信息量时，才称为预期信息增益。涉及确证的数据采集，必须在采样前固定候选及采样、检验方案。

## 3. 假说对象与发现档案

每个假说必须有稳定标识和不可覆盖的版本。可采用如下对象：

```text
H = {
  id, version, parent_ids,
  type, statement, scope,
  representation, model, fitted_parameters,
  predictions, null_hypotheses, alternatives,
  assumptions, complexity,
  provenance: {data_ids, knowledge_version, generator, code_version},
  development: {metrics, stability, novelty, search_history},
  confirmation_plan: {primary_metric, test, effect_threshold,
                      sample_plan, stopping_rule, error_budget},
  evidence_log, status
}
```

`scope` 记录对象、环境、时间及排除条件；`predictions` 写明什么结果会与假说不相容。`representation` 包括缺失值处理、标准化、组合变量等完整变换，避免仅冻结公式却继续修改数据处理。

新颖性只相对于指定知识库版本 $K^{(v)}$ 定义。知识库中尚无匹配项，不等于世界范围内首次发现；近义表达、等价公式和已知推论也应去重。

发现档案记录假说、证据、边界、反例、复现条件与可执行代码。证据等级可标为 E0 探索线索、E1 独立确证支持、E2 新环境或新样本复现。该等级是本系统的记录约定；因果识别另设标签，不能由 E2 自动升级为因果发现。

## 4. 探索目标与确证门槛

初版采用 Pareto 筛选：同时提高开发阶段的预测增益 (G)、重采样稳定性 (S)、相对新颖性 (N)，降低描述长度 (C)：

$$
\max (G(H),S(H),N(H;K^{(v)})),\qquad
\min C(H).
$$

其中一种复杂度与拟合折中是最小描述长度：

$$
C(H)=L(H)+L(D_E\mid H).
$$

编码方式、噪声模型和数据表示需一致，才能比较描述长度。MVP 可以先用公式长度和开发误差近似排序，但不能将该近似宣称为严格 MDL。若改用加权评分，应先处理量纲并在探索阶段固定权重。

确证不使用“新颖性加分抵消弱证据”的总分。候选必须通过有效测试、误差控制、预定效应标准与领域约束。若目标是证明相对基线的改善超过最小有意义差异 $\delta_{\min}$，检验或区间也必须针对该差异设计，不能仅检验改善是否大于零。

结果分为三类：**支持**表示预定主张获得与其强度匹配的证据；**反驳**表示观察与预先声明的预测或边界存在有力不相容；**证据不足**表示当前样本无法裁决。检验不显著通常属于证据不足，不能直接标为反驳或证明零假说。

## 5. 主循环伪代码

```text
输入：任务 T、数据 D、知识库 K、总误差预算 α、资源预算 B
初始化：按观测单位和环境分出 D_E、D_V；封存确证数据
初始化：假说档案 A、保留假说 H_active；轮次 t ← 1

while 仍有预算且未触发停止条件:
    R ← 构造表示(D_E, K)
    P ← 搜索模式(D_E, R)
    H_pool ← 合并去重(H_active, 生成假说(P, K))
    H_batch ← 开发评估与 Pareto 筛选(H_pool, D_E, D_V)

    if H_batch 为空:
        记录本轮搜索失败及消耗
        if 没有可执行且有价值的取证计划: break
        获取探索资料；t ← t + 1
        continue

    α_t ← α / 2^t
    F_t ← 冻结候选版本、变换、参数、检验族和采样/停止协议
    if 没有可用且满足协议的未见确证数据:
        将候选登记为待确证；break
    D_C,t ← 按冻结协议解封或获取尚未见过的确证数据
    E_t ← 执行确证(F_t, D_C,t, α_t)
    A, K ← 归档结果、更新证据等级和版本

    若仍需研究:
        设计区分竞争假说或检验边界的下一轮取证
        将已见 D_C,t 标记为历史数据，可纳入未来探索
        H_active ← 保留或修订假说，新修订具有独立版本
        为下一轮保留新的未见确证数据
    t ← t + 1

输出：发现档案 A、知识库版本、反例与证据不足清单
```

## 6. 数据隔离与跨轮误差控制

三类数据有不同用途：

- **$D_E$：探索数据。**用于特征学习、拟合、模式搜索和探索集内部交叉验证。
- **$D_V$：开发评估数据。**用于候选比较、调参和选择；经过重复反馈后属于开发过程，不能承担独立确证。
- **$D_{C,t}$：第 $t$ 轮确证数据。**可以是预先封存的独立批次，也可以是冻结后按协议采集的新数据。只有候选和协议冻结后才能访问。

划分必须匹配实际预测目标：同一主体的重复记录不能随意跨集合；时间任务避免使用未来信息；跨环境结论需要相应环境证据。预处理参数仅由允许的训练数据估计，之后固定应用于开发和确证数据。

已见确证数据及其结果可以启发修订，但修订版本不能重复使用旧数据证明自身。旧确证记录保留历史身份，新的确证结论必须绑定新版本和仍有效的新证据。工具权限或数据接口应落实这条边界。

原型可选择每轮检验族内使用 Holm 方法控制家族错误率（FWER），跨轮分配：

$$
\alpha_t=\frac{\alpha}{2^t},\quad t\ge1,
\qquad\sum_{t=1}^{\infty}\alpha_t=\alpha.
$$

该方案要求每轮 p 值在既往研究历史和冻结协议下仍然有效。Holm 可处理批内任意相关的有效 p 值，但不能修复数据泄漏、错误采样模型或检验后选择；其家族错误率控制性质见 [R 官方 p.adjust 文档](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/p.adjust.html)。通过跨轮预算与并合界，在这些条件成立时控制整体至少一次错误拒绝的概率。

每轮必须登记完整检验族，包括实际用于声明发现的多个指标、子群或预测。不可删除失败测试后仅校正成功结果。新采集数据也可能受主动选择、聚类、漂移或缺失影响，必须在设计和推断中处理。普通固定样本检验不能在反复查看 p 值后任意提前停止；需要连续监测时，应更换为适用的预定序贯方法。无法构造有效检验时，保留探索性证据标记。

## 7. LLM 职责与停止条件

LLM 辅助提出表示、候选解释、竞争假说、可执行代码草案以及取证建议，并负责把结果转成清晰陈述。统计执行器计算指标、效应量和误差控制结果；符号或数值工具检查公式与约束。所有生成内容需能追溯、运行和核验，LLM 不能凭文本合理性授予证据等级。

停止条件在启动时声明：数据或计算预算耗尽；连续若干轮无合格候选或开发收益低于阈值；剩余实验无法执行；或者预定研究目标及复现要求已满足。停止不意味着其余假说为假，最终输出应明确哪些问题仍缺证据。

## 8. MVP 示例：发现比例变量

构建一个合成任务，以 $X_1,X_2,Y$ 为输入。隐藏生成关系可设为 $Y=a+b(X_1/X_2)+\varepsilon$，用于检查系统能否恢复结构；这仅是算法验证示例，不是现实发现结果。

探索器搜索加、减、乘、除等受限表达式，提出 $Z=X_1/X_2$。冻结前根据领域和数据有效性定义分母安全范围，明确 $|X_2|>\epsilon$ 等适用条件，不能在看到确证结果后更改排除规则。以 $Y=a+bZ$ 为候选，与使用原始变量的预定基线比较。

在 $D_E$ 中拟合参数，在 $D_V$ 中筛选表达式；冻结公式、参数、基线、损失指标、最小改善阈值及检验方案后，才在 $D_{C,t}$ 上评估。可将基线均方误差减候选均方误差作为改善指标，按实际独立观测单位估计不确定性并执行预定检验。

若确证支持，仅记录“比例表示在指定范围内带来达到阈值的预测改善”。然后在新的环境或样本中复现，并专门检查分母接近边界时的失败情况。即使恢复了合成公式，也不能据此宣称发现了因果机制或真实领域的新理论。
