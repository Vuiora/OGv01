### 关键设计决策
1. **各类被试的复现判据逐类写死**（避免「看着差不多」）：关系候选 = 损失严格低于最难超越基线 **且** 斜率符号一致；聚类 = 簇数一致 **且** 成对共簇一致率（Rand 指数，与簇编号无关）达标；变点 = 数量一致 **且** 相对位置偏差达标（相对而非绝对行号，因为重采样后序列长度会变）；不变量 = 判据仍成立 **且** 估计量相对偏差达标。
2. **「不足以给出结论」与「分数」分离**：组数 < `min_groups` 或有效重采样 < `min_effective` 时，`sufficient=False` 并在 `reasons` 说明；此时 `stability` 仍是一个 [0,1] 的数，但报告显式标注不应采用——不把低分辨力的数字伪装成结论。
3. **策略错误类型统一**：P04 的 `prepare_sample` 用 `EquationPolicyError`（非本模块异常体系），直接透传会让调用方漏捕。新增 `_prepare_guarded` 做显式转换（策略含义不变，类型统一为 `StabilityPolicyError`）。
4. **`except StabilityError: raise` 前置**：配置类问题（缺 expression 等）必须向上抛，不能被「本子样本失败」的计数分支静默吞掉——那会把契约错误伪装成统计结论。

### 分类口径（验收标准①）
- **不显著（p > 本轮 Holm 阈值）→ `inconclusive`**，既不构成反驳、也不构成对零假说的证明。
- 显著但方向未披露（`effect` 缺失或为 0）→ `inconclusive`（不猜方向）。
- 显著且方向与备择一致 → `supported`；显著且方向相反 → `refuted`。
- 未产出统计结果 → `failed`（「没算」），严格区别於 `inconclusive`（「算出来不显著」）。
- 整族聚合：全 failed → failed；方向性结论只有一种 → 该种；方向冲突 → `inconclusive`（不择优、不多数表决）。

### 发布边界（验收标准③）
